# ツリーの絶対配置(0.7.0 の束)

構成ラフ(`editorMode: 'webpage'`)で、**選んだ要素から下の DOM ツリーをまとめて絶対配置にする**操作を右クリックに足した。
依頼は「右クリックのコンテキストメニューから、該当の DOM ツリーについて、絶対配置にすべて変換する操作ができるようにしたい」。

0.5.0 の自由配置(`docs/free-layout-2026-09.md`)は、選んだ器の**直下の子だけ**を倒す。カードの中の見出しや画像までは動かせなかった。
この操作は選んだ要素から下へ降り、入れ子の箱まで全部倒す。印のクラスは自由配置と同じものを使うので、
ドラッグの範囲(器の外に出ない)・「自由配置」の札・右パネルの「配置: 自動 / 絶対」・ページ一括の解除がそのまま効く。

## 使い方

右クリックの「配置」に、広い範囲から順に並ぶ。戻す項目は、同じ粒度の項目と入れ替わりで出る。

| 項目 | 出る条件 | すること |
| --- | --- | --- |
| このツリーをすべて絶対配置にする | 選んだ要素の下に、まだ倒していない箱がある | 選んだ要素は流れに残して高さを固定し、下の箱を入れ子まで倒す |
| このツリーの絶対配置を解除する | 下に入れ子の器か、器の外で倒した要素がある | 下の自由配置を全部、元の流し込みへ戻す(並べ替えない) |
| 直下の子だけ絶対配置にする | 選んだ要素が器でなく、下に自由配置も無い | 0.5.0 の「子をすべて絶対配置にする」と同じ |
| 流し込みに戻す | 選んだ要素が 1 段だけの器 | 0.5.0 と同じ(見えている順に並べ直す) |
| このページを自由配置にする… / ページを流し込みに戻す… | 従来どおり | ページの解除は、入れ子の器を含む器をツリーの解除で戻す |

## どこまで倒すか

display は **computed の値**で見る。構成ラフのボタンは `<a class="inline-flex">` で、タグは行内でも箱として描かれる。
flex / grid の子は行内のタグでも箱になる(blockify)。

| 扱い | 対象 | 理由 |
| --- | --- | --- |
| 倒す(箱) | 流れの中にある子(static / relative / sticky)。div・section・li・画像の枠・`inline-flex` のボタンなど | 依頼の「段落・見出し・画像・ボタン・ブロックの箱」 |
| 箱として倒すが、中へは降りない | `p` `h1`〜`h6` `a` `button` `label` `figcaption` `blockquote` `pre`、フォーム部品 | 文字の流れを持つ要素。中を倒すと行の組みが壊れる |
| 同上 | 直下に文字がある要素、直下に行内(display:inline)の子や `<br>` がある要素 | `span` `a` `strong` `br` は段落の中の流れのまま残す |
| 同上 | `img` `picture` `video` `canvas` `iframe` と **svg** | 置換要素。svg の中の図形は HTML の位置指定を持たない |
| 同上 | **table** | `tr` / `td` を絶対配置にすると表の組みが壊れる。表ごと 1 つの箱として動かす |
| 同上 | **ul / ol** は display が flex / grid のときだけ降りて `li` を箱にする。縦に流れるリストは葉 | カードの並びは箱として動かしたい。マーカーや行間で流れるリストは崩れる |
| 同上 | 段組み(`columns`)の器 | 子が段をまたいで分かれ、矩形 1 つで表せない |
| 触らない | `display:none`、`position:fixed` | fixed の基準はビューポートで、倒しても意味が変わるだけ |
| 触らない | 部品(`data-part`)のスロットの外 | 編集できない範囲(ロック)。器にせず(高さも position も書かず)に降り、スロットを新しい起点にする |
| 位置だけ書き直す | 元から `absolute` の要素のうち、基準(包含ブロック)が変わるもの | 親を倒すと基準が変わり、見た目が動く。基準が変わらない飾りは触らない(クラスの位置は幅に追従するので残す) |

部品のロックは `isLockedInsidePart` と同じ規則。**ルート自身にスロットが付いた部品**(例: `ul[data-part=LinkCardGrid][data-slot=list]`)は、
中の `li` がすべてロック扱いになるので、ルートを箱として動かすだけで中は倒れない。

## 仕組み

### 木ごと 1 回で測り、1 回で書き、1 回で確かめる

器ごとに `enableFreeLayout` を再帰で呼ぶと、深いところで 1 つ巻き戻ったときに「途中まで倒れた木」が残る。
`enableFreeLayoutTree` は、何をどう倒すかを先に決め(`planFreeLayoutTree`、DOM は書かない)、全部の矩形を測ってから全部書き、
全部を測り直して 1px を超えてずれた要素が 1 つでもあれば、触った要素の style と class を丸ごと戻す。
履歴(⌘Z)も共同編集の送信も 1 回で済む。

### 位置は矩形から小数で出す

`offsetLeft` / `offsetTop` は整数に丸められる。行の高さが端数(`leading-relaxed` の 22.75px など)の段落の下では、
要素が 0.5px 未満ずつずれて文字のにじみが変わる。入れ子では段ごとに積み上がる。
そこで `getBoundingClientRect` をズーム倍率で割り戻し、器の padding box 基準(枠線の幅とスクロールを引く)の小数にする。
大きさは自由配置と同じく `getComputedStyle` の値(box-sizing と同じ物差し)。

同じ理由で、0.5.0 の `enableFreeLayout` と `setElementAbsolute` も小数に変えた(検証ページの「直下の子だけ」で 0.44% の差が 0 になった)。
変形が掛かった子だけは矩形が外接矩形になるので、変形の影響を受けない offset 系のまま。

### 測る間だけ変形と遷移を止める

回転したアイコン(`rotate-45`)の矩形は外接矩形で、左上が本当の位置と合わない。
測る間だけ `<head>` に一時的な `<style>` を入れ、木の中の `transform` `translate` `rotate` `scale` を `none !important` にする。
変形を戻す瞬間に遷移が走らないよう、`transition: none !important` は変形を戻してから 1 段遅れて外す。
style 属性に混ぜないのは、書き込みで style 属性を触るので戻すときに区別できないため。

### 流れに残る器の外側の手当て

選んだ要素(とスロットの器)は流れに残る。子が抜けると次の 2 つで外側が動くので、ずれた分だけ書き足して測り直す(最大 6 回)。

- **余白の相殺**: 最初 / 最後の子の margin が器を突き抜けていた(padding の無い `section > div > h2.mt-12`)。子が抜けると器が上下にずれる。
  `margin-top` / `margin-bottom` を足す。相殺は最大値で決まるので 1 回で合わないことがある
- **中身で決まっていた幅**: flex の子や inline-block は、子が抜けると幅が縮む。`width` を今の値で固定する

書き足した値は `--gg-flow-margin-top: unset` のように「この変換が書いた」印を残し、解除で外す。

### 書体と画像を待つ

読み込み前に測ると、あとで文字の幅や画像の高さが変わった分だけ固定した寸法とずれる。
変換の前に `document.fonts.ready` と木の中の未読み込みの `img` を待つ(遅延読み込みで来ない画像もあるので最大 1.5 秒)。

## 解除

- **並べ替えない**。ツリーの変換は DOM の順を一度も変えていないので、幾何を外すだけで元の流し込み(元の HTML の順)に戻る。
  見えている順に並べ直す `disableFreeLayout` と違い、`flex-row-reverse` や `order` で並びと見た目の順が食い違う器でも元どおりになる。
  ドラッグで動かしたあとに解除すると、座標は失われ元の位置に戻る
- 深い要素から戻す(親の高さの固定を外すのは、子が流れへ戻ってから)
- 選んだ要素自身が親の器の中の絶対配置なら、その位置と大きさは残す(解除するのは「このツリーの中」だけ)

### 倒した要素の印 `gg-freelayout-item`

解除で幾何を外すのは、この印を持つ要素だけにした。0.5.0 は器の子を全部 `static` に落としていたので、
元から `absolute` だった飾り(`absolute right-8 top-4` の札など)まで流れに落ちた。ツリーでは器が増えるほど巻き込みやすい。
`data-gg-*` は保存で落ちるので、読み直したあとも効く印は class にしている(既存の設計と同じ理由)。

### 元のインラインの幾何の控え `--gg-flow-*`

上書きするプロパティに元からインラインの値があったときだけ、`--gg-flow-width: 480px` のようにカスタムプロパティへ控える。
style 属性の中なので保存 HTML まで届き、読み直したあとの解除でも元の値へ戻る(構成ラフには `style="width: 64px; height: 64px"` の枠がよくある)。
0.5.0 は同一セッション中の退避(`data-gg-prestyle`)しか見なかったので、保存後に解除すると枠の寸法が消えていた。
控えが無い要素は、同一セッション中だけ退避を見る。

### ドラッグ・リサイズの終わりに Tailwind のクラスへ畳まない

`gg-freelayout-item` の要素は、ドラッグ・リサイズ・整列・右パネルの X / Y のあとも `left` `top` `width` `height` をインラインのまま残す
(`convertInlineStylesToTailwind` の呼び出し 7 か所)。畳むと解除のあとに `left-[36px]` のようなクラスだけが残っていた。

## ⌘Z と共同編集

変換は同期の 1 回の DOM 書き換えで、最後に `notifyIframeChange` を 1 回呼ぶ。単独なら履歴 1 段、
`io.collab` に接続中なら 1 回の送信(Y.UndoManager の 1 段)になり、どちらも ⌘Z 1 回で変換の前に戻る。
書体・画像を待っている間に共同編集の反映で要素が差し替わっていたら(`isConnected` が偽)何もしない。

画素の比較は、チャンネルごとに 8 を超える差がある画素を数える。合格の線は 0.1%。

## 分かっている穴

- **実ページの幅がエディタの紙面と違うと合わない**。絶対配置は px 固定なので、構成ラフの紙面(1920px、`main` 1400px)と違う幅で見ると追従しない。
  実ページを 1440px で開くと注釈の欄のぶん `main` が 1019px になり、倒した箱ははみ出す
- 高さを固定するので、倒したあとに文字を足しても下に押し出されない(0.5.0 と同じ)。段落の高さも固定なので、長く書き足すとはみ出す
- `a` / `button` / `p` / 見出しは葉。カード全体が 1 つの `<a class="flex">`(LinkCardGrid)だと、カードは 1 つの箱として動くだけで中は倒れない
- 行内の子を持つ器(`div > span + span` のタグの並び)、縦のリスト、表は 1 つの箱として動く
- `position: sticky` の箱は絶対配置になり、追従しなくなる。`position: fixed` は触らない
- 変形の掛かった static の要素を基準にしている absolute の要素は、測る間だけ基準が変わる。ずれは自己検証で見つかり、木ごと巻き戻る(変換されない)
- CSS アニメーションは止めていない。位置や大きさを動かすアニメーションの途中で測ると、自己検証で巻き戻る
- 解除したあと、変換後に右パネルで入れた幅や余白も幾何として外れる
- マルチフレームのキャンバス表示(`wf-editor:layout = 'canvas'`)での変換は確かめていない(1 ページ表示で検証。キャンバスの既存の回帰は通る)
- 変換の直後に自動保存が走ると選択が外れる(0.5.0 の docs にある既存の挙動)。2 秒ほど経ってから右クリックすると「選択なし」の並びになる
